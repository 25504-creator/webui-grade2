Lesson 14: Exception Handling

💣 What is an Exception?

An exception is an event that occurs during the execution of a program that disrupts the normal flow of instructions. When an error occurs within a method, the method creates an object and hands it off to the runtime system. This object, called an exception object, contains information about the error.

Common examples include trying to divide by zero, or accessing an array element that doesn't exist.

The try-catch Block

To handle exceptions and prevent your program from crashing, you can use a try-catch block.

  • The try block contains the code that might generate an exception.
  • The catch block contains the code that handles the exception if one occurs.
try {
    // Block of code to try
    int[] myNumbers = {1, 2, 3};
    System.out.println(myNumbers[10]); // This will cause an error
} catch (Exception e) {
    // Block of code to handle errors
    System.out.println("Something went wrong.");
    // e.getMessage() can give more details
}
// Output: Something went wrong.

Without the try-catch block, the program would have crashed with an ArrayIndexOutOfBoundsException.

The finally Block

The finally block will be executed regardless of whether an exception was thrown or not. This is useful for code that must always run, such as closing a file or a network connection.

try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Error: Cannot divide by zero.");
} finally {
    System.out.println("The 'try-catch' is finished.");
}

The throw Keyword

The throw statement allows you to create a custom error. This is useful for creating your own validation rules.

static void checkAge(int age) {
    if (age < 18) {
        // Throw an exception if age is below 18
        throw new ArithmeticException("Access denied - You must be at least 18 years old.");
    } else {
        System.out.println("Access granted - You are old enough!");
    }
}

public static void main(String[] args) {
    checkAge(15); // This will throw the exception
}

🎯 Summary

✔ Exceptions are runtime errors that disrupt program flow.
✔ The try block contains code that might cause an exception.
✔ The catch block handles the exception if it occurs.
✔ The finally block executes code after the try-catch, no matter what.
✔ The throw keyword is used to create a custom exception.
