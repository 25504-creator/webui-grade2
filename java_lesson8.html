Lesson 8: Switch Statement

🔀 The Switch Statement

The switch statement is an alternative to a long if-else if-else chain. It allows a variable to be tested for equality against a list of values.

Syntax and Keywords

  • switch (expression): The expression (usually a variable) is evaluated once.
  • case value:: The value of the expression is compared with the values of each case.
  • break;: When Java reaches a break keyword, it breaks out of the switch block. This stops the execution of more code and case testing inside the block.
  • default:: The default keyword specifies some code to run if there is no case match.

💻 Example

This example checks the day of the week and prints a message.

int day = 4;
String dayString;

switch (day) {
    case 1:
        dayString = "Monday";
        break;
    case 2:
        dayString = "Tuesday";
        break;
    case 3:
        dayString = "Wednesday";
        break;
    case 4:
        dayString = "Thursday";
        break;
    case 5:
        dayString = "Friday";
        break;
    default:
        dayString = "Weekend";
        break;
}
System.out.println(dayString); // Output: Thursday

What happens if you forget a break? The code will "fall through" and execute the code in the next case as well, until it hits a break or the end of the switch block.

📚 Practice

Write a program that asks the user to enter a number from 1 to 3. Use a switch statement to print "One", "Two", or "Three" based on their input. Include a default case for invalid numbers.

🎯 Summary

✔ The switch statement selects one of many code blocks to be executed.
✔ Use case to define the different values to check.
✔ The break keyword is crucial to prevent "fall-through".
✔ The default keyword runs when no other case matches.
