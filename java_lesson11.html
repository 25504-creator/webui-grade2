Lesson 11: Methods

🧩 What is a Method?

A method is a block of code that runs only when it is called. You can pass data, known as parameters, into a method. Methods are used to perform certain actions, and they are also known as functions.

Why use methods? To reuse code: define the code once, and use it many times.

Creating and Calling a Method

A method is defined inside a class. To call it, you write the method's name followed by parentheses ().

public class Main {
    // Create a method
    static void myMethod() {
        System.out.println("I just got executed!");
    }

    public static void main(String[] args) {
        // Call the method
        myMethod(); // Output: I just got executed!
        myMethod(); // You can call it multiple times
    }
}

Note: We use the static keyword here so we can call the method directly from main without creating an object. We'll learn more about this in the OOP lesson.

Parameters and Arguments

Information can be passed to methods as parameters. Parameters act as variables inside the method.

public class Main {
    static void sayHello(String name) { // name is a parameter
        System.out.println("Hello, " + name);
    }

    public static void main(String[] args) {
        sayHello("Sok");   // "Sok" is an argument
        sayHello("Dara");  // "Dara" is an argument
    }
}

Return Values

Methods can also return a value. The void keyword means the method does not return anything. If you want it to return a value, you can use a primitive data type (like int or double) instead of void, and use the return keyword inside the method.

public class Main {
    static int add(int x, int y) {
        return x + y; // Returns the sum of x and y
    }

    public static void main(String[] args) {
        int result = add(5, 3);
        System.out.println(result); // Output: 8
    }
}

🎯 Summary

✔ Methods are reusable blocks of code.
✔ Data passed to a method is called a parameter (in the definition) and an argument (when called).
✔ The void keyword indicates that a method does not return a value.
✔ Use the return keyword to send a value back from a method.
