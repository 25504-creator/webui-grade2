Lesson 10: Arrays

🔢 What is an Array?

An array is a data structure that can store a fixed-size collection of elements of the same data type. Think of it as a list of variables.

Declaring and Initializing an Array

You can declare an array by specifying the data type followed by square brackets [].

// Declare an array of strings
String[] cars;

// Initialize the array with values
cars = new String[]{"Volvo", "BMW", "Ford"};

// Or, declare and initialize in one line (more common)
String[] fruits = {"Apple", "Banana", "Orange"};
int[] numbers = {10, 20, 30, 40, 50};

Accessing and Changing Elements

Array elements are accessed by their index number. The index starts from 0.

String[] fruits = {"Apple", "Banana", "Orange"};

// Access the first element (index 0)
System.out.println(fruits[0]); // Output: Apple

// Access the third element (index 2)
System.out.println(fruits[2]); // Output: Orange

// Change an element
fruits[1] = "Mango";
System.out.println(fruits[1]); // Output: Mango

// Get the length of the array
System.out.println(fruits.length); // Output: 3

Looping Through an Array

You can use a for loop to iterate through all the elements of an array.

String[] cars = {"Volvo", "BMW", "Ford"};
for (int i = 0; i < cars.length; i++) {
    System.out.println(cars[i]);
}

// There is also a "for-each" loop, which is easier to write:
for (String car : cars) {
    System.out.println(car);
}

🎯 Summary

✔ Arrays store multiple values of the same type in a single variable.
✔ Array elements are accessed using a zero-based index (array[0], array[1], ...).
✔ The .length property gives the size of the array.
✔ Loops are perfect for processing each element in an array.
