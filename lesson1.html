Lesson 1 : What is HTML?

📖 What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create webpages. Every website you visit is built using HTML together with CSS and JavaScript.

🌍 What can HTML do?

  • Create web pages
  • Add text and headings
  • Insert images
  • Create hyperlinks
  • Create tables
  • Create forms
  • Embed videos and audio
  • Build the structure of a website

📂 Basic HTML Structure

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>Welcome to HTML</p>

</body>

</html>

📝 Explanation

Tag Description
<!DOCTYPE html> Tells the browser this is an HTML5 document.
<html> The root element of the webpage.
<head> Contains information about the webpage.
<title> Shows the page title in the browser.
<body> Contains everything displayed on the webpage.

💻 Example

<p>I am learning HTML.</p>
