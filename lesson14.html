Lesson 14: HTML Best Practices

📖 Why Best Practices Matter

Writing clean, well-structured, and semantic HTML is crucial for creating professional websites. Best practices improve accessibility, search engine optimization (SEO), maintainability, and collaboration with other developers.

✅ Key Best Practices

  • Declare a Doctype: Always start your HTML document with <!DOCTYPE html> to ensure the browser renders the page in standards mode.
  • Use Semantic HTML: Use tags like <header>, <nav>, <main>, and <footer> to describe your content's structure. This helps screen readers and search engines understand your page.
  • Provide Alternative Text for Images: Always use the alt attribute on <img> tags. It's vital for accessibility and is displayed if the image fails to load.
  • Separate Content from Presentation: Use HTML for structure and CSS for styling. Avoid inline styles (e.g., <p style="color: red;">) and outdated tags like <font> or <center>.
  • Validate Your HTML: Use tools like the W3C Markup Validation Service to check for errors in your code.
  • Use Lowercase for Tags and Attributes: While HTML is not case-sensitive, it's a common convention to write all tags and attributes in lowercase for consistency and readability.
  • Close All Tags: Even though some tags are self-closing (e.g., <img>) or optional to close, it's good practice to close all tags properly (e.g., <p>...</p>) for XHTML compatibility and clarity.
  • Add Comments: Use comments <!-- ... --> to explain complex parts of your code for yourself and others.

💻 Example of Good vs. Bad HTML

Bad Practice:

<DIV CLASS="HEADER">MY WEBSITE</DIV>
<br>
<font color="red">Welcome!</font>

Good Practice:

<header>
    <h1>My Website</h1>
</header>
<main>
    <p class="welcome-message">Welcome!</p> <!-- Styled in CSS -->
</main>
