🏛️ What is OOP?

Object-Oriented Programming (OOP) is a programming paradigm based on the concept of "objects", which can contain data (attributes or properties) and code (methods or procedures). The main goal of OOP is to organize complex programs into simple, reusable pieces of code (objects).

Classes and Objects

  • Class: A blueprint for creating objects. For example, a Car class would be a blueprint describing the properties (like color, brand) and methods (like drive, brake) that all cars have.
  • Object: An instance of a class. If Car is the class, then a specific red Toyota is an object of that class.

💻 Example: Creating a Class

Let's create a Dog class in a file named `Dog.java`.

// Dog.java
public class Dog {
    // Attributes (data)
    String name;
    int age;

    // Method (behavior)
    public void bark() {
        System.out.println(name + " says: Woof!");
    }
}

Creating and Using Objects

Now, in our `Main.java` file, we can create and use objects of our Dog class.

// Main.java
public class Main {
    public static void main(String[] args) {
        // Create a new Dog object
        Dog myDog = new Dog();

        // Set its attributes
        myDog.name = "Lucky";
        myDog.age = 3;

        // Call its method
        myDog.bark(); // Output: Lucky says: Woof!

        // Create another Dog object
        Dog anotherDog = new Dog();
        anotherDog.name = "Spot";
        anotherDog.bark(); // Output: Spot says: Woof!
    }
}

Constructors

A constructor is a special method that is used to initialize objects. It is called when an object is created. It must have the same name as the class and does not have a return type.

// Inside the Dog.java class
public class Dog {
    String name;

    // Constructor
    public Dog(String dogName) {
        name = dogName; // Set the name when the object is created
    }

    public void bark() {
        System.out.println(name + " says: Woof!");
    }
}

// In Main.java, creating an object now requires an argument
Dog myDog = new Dog("Lucky");
myDog.bark(); // Output: Lucky says: Woof!

🎯 Summary

✔ OOP helps organize code using objects.
✔ A Class is a template or blueprint.
✔ An Object is an instance of a class.
✔ Objects have attributes (data) and methods (behavior).
✔ A constructor is a special method for creating and initializing an object.
