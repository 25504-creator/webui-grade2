Lesson 5: HTML Images

📖 What is an Image?

Images make webpages attractive and easy to understand. HTML uses the <img> tag to display images.

📚 Image Syntax

<img src="image.jpg" alt="My Image">

📝 Image Attributes

Attribute Description
src Image file location
alt Alternative text
width Image width
height Image height

💻 Example Code

<img src="cat.jpg"
alt="Cute Cat"
width="300">

👀 Example Output

💡 Tips

  • Always write the alt attribute.
  • Keep image file names simple.
  • Resize large images.
  • Use JPG, PNG, SVG or WebP images.
