Lesson 13: Responsive Images

📖 What are Responsive Images?

Responsive images are images that adjust to fit different screen sizes and resolutions. This is crucial for modern web design to ensure images look good and load quickly on both mobile devices and large desktops.

🖼️ Using `srcset` for Resolution Switching

The `srcset` attribute allows you to provide a list of different image sources. The browser will then choose the most appropriate one based on the screen's resolution and size.

<img srcset="image-small.jpg 480w,
             image-large.jpg 800w"
     sizes="(max-width: 600px) 480px,
            800px"
     src="image-large.jpg"
     alt="A responsive image">

- `srcset` defines the set of images and their widths (`w` descriptor).
- `sizes` tells the browser how wide the image will be at different viewport widths.
- `src` is a fallback for older browsers.

🎨 The <picture> Element for Art Direction

The <picture> element gives you more control. You can use it to show completely different images for different screen sizes (art direction).

<picture>
  <source media="(min-width: 650px)" srcset="img_pink_flowers.jpg">
  <source media="(min-width: 465px)" srcset="img_white_flower.jpg">
  <img src="img_orange_flowers.jpg" alt="Flowers">
</picture>

The browser will use the first `<source>` element that matches the media query. The `<img>` is the default and is required.

Resize your browser window to see the image change. (Note: This example uses placeholder images that look the same but would be different files in a real project).

💡 Tips

  • Use `srcset` when you have the same image in different sizes.
  • Use `<picture>` when you need to show different images or crop an image differently on various screens (art direction).
  • Always include a fallback `<img>` element inside `<picture>`.
  • Optimizing images is key to a fast website.
