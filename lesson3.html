Lesson 3: Headings & Paragraphs

📖 What are Headings?

HTML headings are used for titles and subtitles. There are six heading tags: <h1> to <h6>.

📚 Heading Tags

Tag Description
<h1> Largest heading (Main title)
<h2> Second level heading
<h3> Third level heading
<h4> Fourth level heading
<h5> Fifth level heading
<h6> Smallest heading

💻 Example

<h1>Heading 1</h1>

<h2>Heading 2</h2>

<h3>Heading 3</h3>

<h4>Heading 4</h4>

<h5>Heading 5</h5>

<h6>Heading 6</h6>

📖 What is a Paragraph?

The <p> tag is used to write paragraphs. Every paragraph starts on a new line.

💻 Paragraph Example

<p>

Welcome to CodeKhmer Learning.

This is my first HTML paragraph.

</p>

🌍 Output

Heading 1

Heading 2

Heading 3

Welcome to CodeKhmer Learning. This is an HTML paragraph.

💡 Tips

  • Use only one <h1> on a page.
  • Use headings in order.
  • Write paragraphs using <p>.
  • Do not use headings just to make text bigger.

📝 Exercise

Create a webpage containing:

  1. One <h1>
  2. One <h2>
  3. One <h3>
  4. Two paragraphs

🎯 Summary

✔ HTML has six heading tags.
✔ Headings organize webpage content.
✔ Paragraphs are written using the <p> tag.
✔ Good headings improve readability.
