Lesson 13: Inheritance & Polymorphism

🧬 Inheritance

Inheritance is a core concept of OOP where one class can inherit attributes and methods from another class. This promotes code reusability.

  • Superclass (or parent): the class being inherited from.
  • Subclass (or child): the class that inherits from another class.

We use the extends keyword to create a subclass.

// Superclass
class Animal {
    public void eat() {
        System.out.println("This animal eats food.");
    }
}

// Subclass
class Dog extends Animal {
    public void bark() {
        System.out.println("The dog barks.");
    }
}

// In main method:
Dog myDog = new Dog();
myDog.eat();  // Inherited from Animal
myDog.bark(); // Defined in Dog

🎭 Polymorphism

Polymorphism means "many forms". In OOP, it's the ability of an object to take on many forms. The most common use of polymorphism in Java is when a parent class reference is used to refer to a child class object.

It allows us to perform a single action in different ways. This is often achieved through method overriding.

Method Overriding

If a subclass has the same method as declared in the parent class, it is known as method overriding. The subclass can provide its own specific implementation of the method.

class Animal {
    public void makeSound() {
        System.out.println("The animal makes a sound");
    }
}

class Pig extends Animal {
    // Overriding the makeSound method
    @Override
    public void makeSound() {
        System.out.println("The pig says: wee wee");
    }
}

class Cat extends Animal {
    // Overriding the makeSound method
    @Override
    public void makeSound() {
        System.out.println("The cat says: meow");
    }
}

// In main method:
Animal myAnimal = new Animal();
Animal myPig = new Pig(); // Animal reference, but Pig object
Animal myCat = new Cat(); // Animal reference, but Cat object

myAnimal.makeSound(); // Output: The animal makes a sound
myPig.makeSound();    // Output: The pig says: wee wee
myCat.makeSound();    // Output: The cat says: meow

The @Override annotation is not required, but it is good practice as it helps the compiler check if you are correctly overriding a method.

🎯 Summary

✔ Inheritance allows a class to inherit properties and methods from another class using the extends keyword.
✔ Polymorphism allows objects to be treated as instances of their parent class, enabling a single action to have different behaviors.
✔ Method Overriding is when a subclass provides a specific implementation for a method that is already defined in its superclass.
✔ These concepts are fundamental to writing flexible and maintainable object-oriented code.
