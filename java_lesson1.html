Lesson 1: Introduction to Java

📖 What is Java?

Java is a popular, high-level, object-oriented programming language. It was designed to have as few implementation dependencies as possible, which means a Java program can run on any platform that has a Java Virtual Machine (JVM). This principle is known as "Write Once, Run Anywhere" (WORA).

🌟 Key Features of Java

  • Platform Independent: Java code is compiled into bytecode, which can run on any device with a JVM.
  • Object-Oriented: Everything in Java is an object, which helps in building modular and reusable code.
  • Robust and Secure: Java has strong memory management and security features, making it reliable for large-scale applications.
  • Widely Used: It's used for web applications, Android apps, enterprise software, big data, and much more.

💻 "Hello, World!" in Java

Here is what a simple Java program looks like:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
