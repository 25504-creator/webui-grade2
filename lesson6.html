Lesson 6: HTML Lists

📖 What is a List?

HTML lists are used to organize information clearly. There are three types of HTML lists.

📚 Types of Lists

Tag Description
<ul> Unordered List (Bullet List)
<ol> Ordered List (Number List)
<dl> Description List

💻 Example 1 : Unordered List

<ul>
   <li>HTML</li>
   <li>CSS</li>
   <li>JavaScript</li>
</ul>
  • HTML
  • CSS
  • JavaScript

💻 Example 2 : Ordered List

<ol>
   <li>Wake up</li>
   <li>Study HTML</li>
   <li>Practice Coding</li>
</ol>
  1. Wake up
  2. Study HTML
  3. Practice Coding

💻 Example 3 : Description List

<dl>
<dt>HTML</dt>
<dd>Markup Language</dd>

<dt>CSS</dt>
<dd>Styles Web Pages</dd>
</dl>
HTML
Markup Language
CSS
Styles Web Pages

💡 Tips

  • Use <ul> when the order is not important.
  • Use <ol> when the order is important.
  • Use <li> inside both ul and ol.
  • Use <dl> for terms and definitions.

🎯 Summary

✔ HTML provides three list types.
✔ Use <ul> for bullet lists.
✔ Use <ol> for numbered lists.
✔ Use <dl> for description lists.
✔ Use <li> to create list items.
