Lesson 4: HTML Links

📖 What is a Link?

HTML links allow users to move from one webpage to another. Links are created using the <a> tag.

📚 Basic Syntax

<a href="https://www.google.com">
Visit Google
</a>

📝 Link Attributes

Attribute Description
href Destination URL
target="_blank" Open in new tab
title Tooltip text

💻 Examples

<a href="https://www.google.com">
Google
</a>

<a href="page2.html">
Next Page
</a>

<a href="https://www.youtube.com"
target="_blank">
YouTube
</a>

👀 Output

Visit Google

Visit YouTube

💡 Tips

  • Always use the href attribute.
  • Use target="_blank" to open a new tab.
  • Use meaningful link text.
  • Avoid writing "Click Here".

🎯 Summary

✔ HTML links are created using the <a> tag.
✔ The href attribute specifies the destination.
✔ Use target="_blank" to open a new tab.
✔ Links help users navigate between webpages.
