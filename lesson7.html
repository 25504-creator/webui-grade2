Lesson 7: HTML Tables

📖 What is a Table?

An HTML table is used to organize data into rows and columns. Tables are useful for schedules, prices, student lists, and reports.

📚 Table Tags

Tag Description
<table> Creates a table
<tr> Creates a row
<th> Creates a header cell
<td> Creates a normal data cell

💻 Basic Table Example

<table>

    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>John</td>
        <td>20</td>
    </tr>

</table>

👀 Output

Name Age
John 20
Emma 22
David 19

📌 colspan Example

<td colspan="2">Student</td>
Student Information
Name John

📌 rowspan Example

<td rowspan="2">HTML</td>
Course Level
HTML Beginner
Advanced

💡 Tips

  • Use <th> for table headers.
  • Use <td> for data.
  • Use colspan to merge columns.
  • Use rowspan to merge rows.
  • Use CSS to make tables beautiful.
