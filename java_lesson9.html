Lesson 9: Loops

🔄 What are Loops?

Loops are used to execute a block of code repeatedly as long as a certain condition is met. They are essential for automating repetitive tasks.

1. The while Loop

The while loop executes a block of code as long as its condition is true.

int i = 0;
while (i < 5) {
    System.out.println(i);
    i++; // Increment i, otherwise the loop will run forever!
}
// Output: 0, 1, 2, 3, 4

2. The for Loop

The for loop is often used when you know exactly how many times you want to loop.

It consists of three parts: initialization, condition, and increment/decrement.

// for (initialization; condition; increment)
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
// Output: 0, 1, 2, 3, 4

3. The do-while Loop

This loop is similar to the while loop, but it will always execute the code block at least once, because the condition is checked at the end.

int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 5);
// Output: 0, 1, 2, 3, 4

📚 Practice

Use a for loop to print all the even numbers from 2 to 20.

Hint: You can use the modulus operator (%) to check if a number is even, or you can increment your loop variable by 2.

🎯 Summary

✔ Loops execute code repeatedly.
✔ The while loop runs as long as a condition is true.
✔ The for loop is ideal for a fixed number of iterations.
✔ The do-while loop always executes at least once.
