Lesson 6: Input & Output

📤 Output in Java

As we've seen, the primary way to display output in the console is using System.out.println().

  • System.out.println(): Prints the text and moves the cursor to a new line.
  • System.out.print(): Prints the text but keeps the cursor on the same line.
System.out.print("Hello, ");
System.out.print("World!");
// Output: Hello, World!

📥 Input in Java with Scanner

To get input from the user, we can use the Scanner class, which is part of Java's utility library.

Step 1: Import the Scanner class. This must be at the very top of your file.

import java.util.Scanner;

Step 2: Create a Scanner object. This object will read input from the keyboard (System.in).

Scanner myScanner = new Scanner(System.in);

Step 3: Read input. Use methods like nextLine() to read text or nextInt() to read an integer.

System.out.println("Enter your name:");
String name = myScanner.nextLine(); // Reads a line of text

System.out.println("Enter your age:");
int age = myScanner.nextInt(); // Reads an integer

💻 Full Example

import java.util.Scanner; // Step 1

public class UserInput {
    public static void main(String[] args) {
        Scanner myScanner = new Scanner(System.in); // Step 2

        System.out.println("Enter your username:");
        String userName = myScanner.nextLine(); // Step 3

        System.out.println("Username is: " + userName);
        
        myScanner.close(); // Good practice to close the scanner
    }
}
