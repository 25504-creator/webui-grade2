🚀 Your First Java Application Project

Congratulations on completing the Java course! Now it's time to put everything you've learned into practice by building a simple console application. This project will be a "Simple Calculator".

📋 Project Requirements

Create a Java console application that performs basic arithmetic operations. The program should:

  1. Welcome the user and display the available operations (+, -, *, /).
  2. Ask the user to enter the first number.
  3. Ask the user to enter an operator.
  4. Ask the user to enter the second number.
  5. Use a switch statement to determine which operation to perform based on the operator input.
  6. Calculate and display the result. For example: "Result: 5 + 3 = 8".
  7. Handle potential errors, such as division by zero, using a try-catch block.
  8. Use a loop to ask the user if they want to perform another calculation.

Concepts to use: Variables, Scanner, if/switch, loops, methods, and exception handling.

💡 High-Level Code Structure

Here is a possible structure for your `main` method. Try to fill in the details yourself!

public static void main(String[] args) {
    Scanner scanner = new Scanner(System.in);
    String anotherCalculation;

    do {
        // 1. Get user input for number1, operator, number2

        try {
            double result = 0;
            // 2. Use a switch statement to calculate the result
            switch (operator) {
                case '+':
                    // add
                    break;
                // ... other cases
                case '/':
                    if (number2 == 0) {
                        throw new ArithmeticException("Cannot divide by zero!");
                    }
                    // divide
                    break;
                default:
                    System.out.println("Invalid operator!");
                    continue; // Skip to the next loop iteration
            }

            // 3. Print the result

        } catch (Exception e) {
            // 4. Catch any errors and print a message
            System.out.println("Error: " + e.getMessage());
        }

        // 5. Ask user if they want to do another calculation
        System.out.println("Do another calculation? (yes/no)");
        anotherCalculation = scanner.next();

    } while (anotherCalculation.equalsIgnoreCase("yes"));

    System.out.println("Calculator closed. Thank you!");
    scanner.close();
}
