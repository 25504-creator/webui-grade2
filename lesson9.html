Lesson 9: HTML Forms

📖 What is a Form?

HTML forms are used to collect user input, such as text, email, passwords, and choices. Forms are essential for login pages, contact pages, and search bars.

📚 Common Form Tags

Tag Description
<form> The container for a form.
<input> The most used form element. Can be of many types (text, password, radio, checkbox, submit).
<label> A label for an <input> element.
<textarea> A multi-line text input area.
<select> A drop-down list.
<option> An option in a drop-down list.
<button> A clickable button.

💻 Example Code

<form action="/submit-form" method="post">

  <label for="name">Name:</label>
  <input type="text" id="name" name="username">

  <label for="email">Email:</label>
  <input type="email" id="email" name="useremail">

  <label for="message">Message:</label>
  <textarea id="message" name="usermessage" rows="4"></textarea>

  <label for="country">Country:</label>
  <select id="country" name="usercountry">
    <option value="kh">Cambodia</option>
    <option value="jp">Japan</option>
  </select>

  <input type="submit" value="Send">

</form>

👀 Example Output



💡 Tips

  • Always use the <label> tag for form controls to improve accessibility.
  • The `for` attribute of the <label> should match the `id` of the <input>.
  • The `name` attribute is important for sending the form data to a server.
  • Use different `type` attributes for <input> to get different controls (e.g., `password`, `radio`, `checkbox`).
