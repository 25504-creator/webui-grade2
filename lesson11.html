Lesson 11: Semantic HTML

📖 What is Semantic HTML?

Semantic HTML tags clearly describe their meaning to both the browser and the developer. For example, <header>, <footer>, and <article> are more descriptive than <div> and <span>.

Using semantic tags improves SEO (Search Engine Optimization) and accessibility.

📚 Common Semantic Tags

Tag Description
<header>Defines a header for a document or section.
<nav>Defines a set of navigation links.
<main>Specifies the main content of a document.
<section>Defines a section in a document.
<article>Defines an independent, self-contained piece of content.
<aside>Defines content aside from the content it is placed in (like a sidebar).
<footer>Defines a footer for a document or section.
<figure>Specifies self-contained content, like illustrations, diagrams, photos.
<figcaption>Defines a caption for a <figure> element.

💻 Example Code

<body>
    <header>
        <h1>My Website</h1>
        <nav> ... navigation links ... </nav>
    </header>

    <main>
        <article>
            <h2>Article Title</h2>
            <p>Article content...</p>
        </article>
        <aside>
            <h3>Related Links</h3>
        </aside>
    </main>

    <footer>
        <p>Copyright 2024</p>
    </footer>
</body>

👀 Example Layout

<header>
<nav>
<section> with <article>
<aside>
<footer>

💡 Tips

  • Use semantic tags to give meaning to your page structure.
  • Don't replace all your `div`s. Use `div`s for styling and grouping when no semantic element is appropriate.
  • A page should typically have one `<main>` element.

📚 Practice

Structure a simple blog post page using semantic HTML, including:

  1. A header with the blog title and navigation.
  2. A main content area.
  3. An article for the blog post itself.
  4. A footer with copyright information.
