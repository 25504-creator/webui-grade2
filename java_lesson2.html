Lesson 2: Installing Java & IDE

🛠️ Setting Up Your Environment

Before you can write and run Java code, you need to set up your development environment. This involves two main steps: installing the Java Development Kit (JDK) and choosing an Integrated Development Environment (IDE).

1. Installing the JDK

The JDK includes the tools needed to develop and run Java applications.

  • JDK (Java Development Kit): For developers. It includes the compiler, debugger, and the JRE.
  • JRE (Java Runtime Environment): For users. It allows you to run Java applications but not develop them.
  • JVM (Java Virtual Machine): An abstract machine that runs the Java bytecode. It's part of the JRE.

You can download the latest JDK from Oracle's website or use an open-source version like Eclipse Temurin (Adoptium).

2. Choosing an IDE

An IDE is a software application that provides comprehensive facilities to computer programmers for software development. An IDE normally consists of a source code editor, build automation tools, and a debugger.

Popular IDEs for Java include:

  • IntelliJ IDEA: Very powerful and popular, with a free Community Edition.
  • Eclipse: A classic, open-source, and highly extensible IDE.
  • Visual Studio Code (VS Code): A lightweight but powerful code editor with great Java support through extensions.

For beginners, VS Code with the "Extension Pack for Java" is a great starting point.

✅ Verifying Installation

After installing the JDK, open your terminal or command prompt and type the following commands to check if it was installed correctly:

java -version
javac -version

If both commands show a version number, your installation was successful!
