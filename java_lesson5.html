Lesson 5: Operators

🧮 What are Operators?

Operators are special symbols used to perform operations on variables and values. For example, + is an operator used for addition.

1. Arithmetic Operators

Used to perform common mathematical operations.

int x = 10;
int y = 3;
System.out.println(x + y); // 13 (Addition)
System.out.println(x - y); // 7 (Subtraction)
System.out.println(x * y); // 30 (Multiplication)
System.out.println(x / y); // 3 (Division, integer division truncates)
System.out.println(x % y); // 1 (Modulus - remainder of division)

2. Comparison Operators

Used to compare two values. The result is always a boolean (true or false).

int a = 5;
int b = 7;
System.out.println(a == b); // false (Equal to)
System.out.println(a != b); // true (Not equal to)
System.out.println(a > b);  // false (Greater than)
System.out.println(a < b);  // true (Less than)
System.out.println(a >= 5); // true (Greater than or equal to)

3. Logical Operators

Used to determine the logic between variables or values.

int age = 25;
boolean hasLicense = true;

// Logical AND (&&): both conditions must be true
System.out.println(age > 18 && hasLicense); // true

// Logical OR (||): at least one condition must be true
System.out.println(age < 20 || hasLicense); // true

// Logical NOT (!): reverses the boolean value
System.out.println(!hasLicense); // false

4. Assignment Operators

Used to assign values to variables. You can combine them with arithmetic operators for shorthand.

int score = 100;

score += 10; // same as score = score + 10; Now score is 110
score -= 20; // same as score = score - 20; Now score is 90
score *= 2;  // same as score = score * 2;  Now score is 180
