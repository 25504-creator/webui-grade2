Lesson 15: HTML Mini Project

🚀 Your First Website Project

Congratulations on reaching the final lesson! It's time to combine everything you've learned to build a complete, single-page website. This project will be a simple personal portfolio page.

📋 Project Requirements

Create a single HTML file named `portfolio.html`. The page must include the following sections, using semantic HTML tags:

  1. A <header>: Containing your name inside an <h1> tag.
  2. A <nav>: With links that jump to the "About Me", "My Skills", and "Contact" sections of the page. (Hint: Use IDs and anchor links like <a href="#about">).
  3. A <main> content area which contains three <section>s:
    • About Me (id="about"): An <h2> title, a paragraph about yourself, and an image of you (or a placeholder).
    • My Skills (id="skills"): An <h2> title and an unordered list (<ul>) of skills you are learning (e.g., HTML, CSS).
    • Contact (id="contact"): An <h2> title and a simple contact form with fields for Name, Email, and a Submit button.
  4. A <footer>: Containing a copyright notice (e.g., © 2024 Your Name).
