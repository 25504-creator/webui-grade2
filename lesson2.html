Lesson 2: HTML Document Structure

📖 What is an HTML Document?

Every HTML webpage follows the same basic structure. The browser reads the HTML file from top to bottom.

📂 Basic HTML Structure

<!DOCTYPE html>
<html>

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>Welcome to HTML</p>

</body>

</html>

📝 Explanation

Tag Description
<!DOCTYPE html> Declares HTML5 document.
<html> The root element.
<head> Contains page information.
<meta charset> Supports different languages.
<title> Browser tab title.
<body> Everything shown on the webpage.

💡 Tips

  • Always start with <!DOCTYPE html>
  • Every page has one <html> tag.
  • The <head> contains page information.
  • The <body> contains everything visitors see.
