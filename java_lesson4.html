Lesson 4: Variables & Data Types

📦 What are Variables?

Variables are containers for storing data values. In Java, each variable must have a specific data type, which determines the size and type of value it can store.

📊 Common Data Types

Java has two main categories of data types: primitive and non-primitive (or reference).

Primitive Types

TypeDescriptionExample
intStores whole numbers (integers)int age = 25;
doubleStores floating-point numbers (with decimals)double price = 19.99;
charStores single characterschar grade = 'A';
booleanStores true or false valuesboolean isLoggedIn = true;

Non-Primitive Type

The most common non-primitive type is String, which is used to store text.

TypeDescriptionExample
StringStores a sequence of characters (text)String name = "Sok";

💻 Declaring and Using Variables

To create a variable, you must specify the type and assign it a value:

// Syntax: type variableName = value;

int myNumber = 10;
double myDouble = 5.75;
char myChar = 'D';
boolean myBool = false;
String myText = "Hello Java";

// You can print variables to see their values
System.out.println(myText); // Output: Hello Java
System.out.println(myNumber); // Output: 10

// You can also change the value of a variable
myNumber = 20;
System.out.println(myNumber); // Output: 20
