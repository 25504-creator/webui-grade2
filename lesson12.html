Lesson 12: HTML5 Features

📖 What's New in HTML5?

HTML5 is the latest version of HTML, and it introduced many new features to make web development easier and more powerful. This includes new semantic elements, new form input types, and new APIs for graphics and multimedia.

🆕 New Form Input Types

HTML5 added several new input types for forms, which can provide better user experience and validation on mobile devices.

  • color: A color picker.
  • date: A date picker.
  • email: For email addresses (with validation).
  • number: For numerical input.
  • range: A slider control.
  • search: A search field.
  • tel: For telephone numbers.
  • url: For URLs.
<label for="favcolor">Select your favorite color:</label>
<input type="color" id="favcolor" name="favcolor">

<label for="birthday">Birthday:</label>
<input type="date" id="birthday" name="birthday">

🎨 Graphics with <canvas> and <svg>

<canvas> is used to draw graphics on the fly, via JavaScript. It's great for games, graphs, and photo manipulations.

<svg> (Scalable Vector Graphics) is used to define vector-based graphics for the Web. SVG images can be scaled to any size without losing quality. 

<!-- Canvas is just a container for graphics -->
<canvas id="myCanvas" width="200" height="100"></canvas>

<!-- SVG draws the shape directly in HTML -->
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" stroke="green" stroke-width="4" fill="yellow" />
</svg>

💡 Other Notable Features

  • Geolocation API: Allows the browser to get the geographical position of the user.
  • Drag and Drop API: Provides a simple way to implement drag-and-drop functionality.
  • Web Storage (localStorage and sessionStorage): A way to store data on the client-side, more powerful than cookies.

📚 Practice

  2. Try to draw a simple rectangle or circle using SVG.
