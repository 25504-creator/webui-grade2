Lesson 3: First Java Program

👋 Hello, World!

It's a tradition in programming to start with a "Hello, World!" program. This simple program will teach you the basic structure of a Java application and how to print output to the console.

📂 File and Class Name

In Java, the name of the public class must match the name of the file. For example, if your class is named `MyFirstApp`, the file must be saved as `MyFirstApp.java`.

💻 The Code

Create a new file named `Main.java` and type the following code:

public class Main {
    public static void main(String[] args) {
        // This line prints "Hello, World!" to the console
        System.out.println("Hello, World!");
    }
}

🔍 Code Breakdown

  • public class Main: This declares a public class named `Main`. Every Java application must have at least one class.
  • public static void main(String[] args): This is the main method. It's the entry point of your application. The code inside this method will be executed when you run the program.
  • System.out.println("Hello, World!");: This is a statement that prints the text "Hello, World!" to the console, followed by a new line.
  • // ...: This is a comment. The compiler ignores it. It's used to explain the code.

🚀 How to Compile and Run

If you are using an IDE like VS Code or IntelliJ, you can usually just click a "Run" button. If you are using the terminal:

  1. Compile: `javac Main.java` (This creates a `Main.class` file)
  2. Run: `java Main`

Output:

Hello, World!
