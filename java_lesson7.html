Lesson 7: If Statements

🤔 Making Decisions

In programming, we often need to perform different actions based on different conditions. The if statement allows us to execute a block of code only if a specified condition is true.

Basic if Statement

The code inside the curly braces {} only runs if the condition in the parentheses () is true.

int age = 20;
if (age >= 18) {
    System.out.println("You are an adult.");
}

The if-else Statement

Use the else keyword to specify a block of code to be executed if the condition is false.

int time = 22;
if (time < 18) {
    System.out.println("Good day.");
} else {
    System.out.println("Good evening.");
}
// Output: Good evening.

The if-else if-else Statement

Use the else if keyword to specify a new condition to test, if the first condition is false.

int score = 85;
if (score >= 90) {
    System.out.println("Grade: A");
} else if (score >= 80) {
    System.out.println("Grade: B");
} else {
    System.out.println("Grade: C or lower");
}
// Output: Grade: B

📚 Practice

Write a program that asks the user for a number. Then, use if-else statements to print whether the number is positive, negative, or zero.
