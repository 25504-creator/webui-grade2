Lesson 8: HTML Text Formatting

📖 What is Text Formatting?

HTML provides several tags to format text, making it bold, italic, or highlighted. These tags help to emphasize certain parts of your content.

📚 Formatting Tags

Tag Description
<b> Bold text
<strong> Important text (semantically bold)
<i> Italic text
<em> Emphasized text (semantically italic)
<mark> Marked or highlighted text
<small> Smaller text
<del> Deleted text (strikethrough)
<ins> Inserted text (underline)
<sub> Subscript text (e.g., H₂O)
<sup> Superscript text (e.g., E=mc²)

💻 Example Code

<p>This is <b>bold</b> and this is <strong>important</strong>.</p>
<p>This is <i>italic</i> and this is <em>emphasized</em>.</p>
<p>Do not forget to buy <mark>milk</mark> today.</p>
<p>My favorite color is <del>blue</del> <ins>red</ins>.</p>
<p>H<sub>2</sub>O and E=mc<sup>2</sup>.</p>

👀 Example Output

This is bold and this is important.

This is italic and this is emphasized.

Do not forget to buy milk today.

My favorite color is blue red.

H2O and E=mc2.

💡 Tips

  • Use for important text, not just for bolding.
  • Use for emphasized text, not just for italics.
  • These tags can be combined.
